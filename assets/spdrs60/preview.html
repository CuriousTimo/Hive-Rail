Hive-Rail SpDrS60 tiles

Hive-Rail's own drawings of the Siemens SpDrS60 panel; each tile once, its state as classes.

A small terminus throat

Joining test: curves in a row and a turnout's branch

track-straight

Track, straight; with platform above, below or both (platform-top, platform-bottom)

track-curve

Track, 45-degree curve: from the middle of the left edge to the middle of the bottom edge

turnout-right

Turnout, right hand (Weiche rechts): trunk at the left, straight to the right, diverging down (to the right when running right); the point at the left

turnout-left

Turnout, left hand (Weiche links): trunk at the left, straight to the right, diverging up (to the left when running right); the point at the left

crossing

Crossing (Kreuzung), two tiles wide: straight track and a 45-degree track from the top of the right tile to the bottom of the left tile

double-slip

Double slip (Doppelkreuzungsweiche), two tiles wide: a crossing with both slip curves; the point in the middle

buffer-stop

Buffer stop (Prellbock) at the right end

sensor

Track with an occupancy sensor (Rückmelder): a green dot while free, red while occupied; it can lie along a platform

sensor-curve

Curve with an occupancy sensor: the dot in the middle of the curve

signal-hv-block

H/V block signal for trains running right: H/V block signal (Blocksignal): Hp 0 (one red), Hp 1

signal-hv-entry

H/V entry signal for trains running right: H/V entry signal (Einfahrsignal): Hp 0 (one red), Hp 1, Hp 2

signal-hv-departure

H/V departure signal for trains running right: H/V departure signal (Ausfahrsignal): Hp 0 (two reds), Hp 1, Hp 2, Hp 0 + Sh 1

signal-hv-block-distant

H/V block signal with the distant signal below it on the same mast, for trains running right; two tiles wide: H/V block signal with the distant signal below it on the same mast: the main signal's aspects, with Vr 0, Vr 1 or Vr 2 (dark at Hp 0)

signal-hv-entry-distant

H/V entry signal with the distant signal below it on the same mast, for trains running right; two tiles wide: H/V entry signal with the distant signal below it on the same mast: the main signal's aspects, with Vr 0, Vr 1 or Vr 2 (dark at Hp 0)

signal-hv-departure-distant

H/V departure signal with the distant signal below it on the same mast, for trains running right; two tiles wide: H/V departure signal with the distant signal below it on the same mast: the main signal's aspects, with Vr 0, Vr 1 or Vr 2 (dark at Hp 0)

signal-hv-distant

H/V distant signal for trains running right: H/V light distant signal (Lichtvorsignal): Vr 0, Vr 1, Vr 2; the white Zusatzlicht as an option

signal-ks-main

Ks main signal for trains running right: Ks main signal: red, the green below it; Hp 0, Ks 1; Sh 1 (departure signals)

signal-ks-multi

Ks multi-section signal for trains running right: Ks multi-section signal (Mehrabschnittssignal): Hp 0, Ks 1, Ks 2; Sh 1 (departure signals); the upper white

signal-ks-distant

Ks distant signal for trains running right: Ks distant signal (Ks-Vorsignal): Ks 1 (green), Ks 2 (yellow); the upper white

signal-sh

Light shunting signal (Lichtsperrsignal) for trains running right: Light shunting signal (Lichtsperrsignal): Sh 0 (two reds), Sh 1 (two whites rising to the right)

level-crossing

Level crossing (Bahnübergang): the road across the track, lamps lit while closed

district-border

District border (Hive-Rail): a section joint with each side's district colour

train-number

Train number field (Zugnummernmelder) on the track; the page sets its number; it can lie along a platform

lamp

Lamp (street or building light): lit while on

windmill

Windmill: its sails turn while it runs

action

Action (a Viessmann eMotion scene or another animated accessory): lit while it runs

plate

Name plate (track, signal or turnout name) in its own cell; the page sets its text
